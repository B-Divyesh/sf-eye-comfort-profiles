Privacy

Eye Comfort Profiles is local-first. The extension does not operate an account system, record your reading, send browsing history to us, or include analytics, advertising, cookies, or third-party runtime scripts.

What stays on your device

The extension stores named profiles, typography and layout values, and website selections in the browser’s local extension storage. A website is saved only when you choose “Save to this website.” Your exported backup is created locally and saved wherever you direct your browser.

Page access

The extension applies saved profiles only on regular websites. It uses the website for matching and changes presentation with CSS. It does not transmit page content, URLs, or browsing activity to us.

Purchases and licenses

If you buy the optional supporter unlock, checkout opens through Sociobot. The extension sends the license token to Sociobot at most once per day. A cached license verdict and token are stored locally, so reading controls never wait for verification.

Website data

This site sets no analytics cookies and includes no tracking pixels. Standard hosting logs may temporarily contain IP address, user agent, request path, and timestamp for security and reliability.

Your control

Delete profiles in the extension, remove website selections, clear extension storage, or uninstall the extension at any time. Uninstalling removes its local data. You can also export a portable JSON backup before doing so.

Contact

For privacy questions, open an issue in the project’s public source repository.
